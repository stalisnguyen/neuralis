# stalis-study.vercel.app

Source of the shared home page, privacy policy and terms for the four study apps (Catalis, Stalong, Calculis, Neuralis).
Google sign-in (project stalis-study-apps) points to these pages, so keep them online and accurate.

Hosted as its own Vercel project `stalis-study` (team inner-world), deployed from these files.
This folder is not part of the Neuralis site (see .vercelignore).

When the data the apps collect or the services they use change, update privacy.html and terms.html
(both the Vietnamese and English parts, and the effective date), then redeploy the stalis-study project.
